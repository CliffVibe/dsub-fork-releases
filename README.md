# DSUB Fork — releases

Installers of **DSUB Fork (DikirdoSUB)**, a fork of [Aegisub](https://github.com/TypesettingTools/Aegisub) 3.5.0 for ASS typesetting, rendering and AI-assisted checks. This repository holds only the builds; the program checks it for updates by itself.

- **Install:** download `DSUB-Fork-…-x64-setup.exe` from the [latest release](../../releases/latest) and run it (no administrator rights needed). Installing over an older version keeps your settings, dictionaries, presets and glossaries.
- **Updates:** at start (once a day) and from *Help → Check for Updates* the program reads [`update.json`](../../releases/latest/download/update.json) here and offers the new build. *Help → Roll Back the Update* installs the build before the current one.

# DSUB Fork — сборки

Установщики **DSUB Fork (DikirdoSUB)** — форка Aegisub 3.5.0 для тайпсеттинга, рендера и AI-проверок. Здесь только сборки; программа сама проверяет этот репозиторий на обновления.

- **Установка:** скачайте `DSUB-Fork-…-x64-setup.exe` из [последнего релиза](../../releases/latest) и запустите (права администратора не нужны). Установка поверх старой версии сохраняет настройки, словари, пресеты и глоссарии.
- **Обновления:** при запуске (раз в сутки) и через «Помощь → Проверить обновления» программа читает отсюда `update.json` и предлагает новую сборку. «Помощь → Откатить обновление» ставит предыдущую.
- **Исходники** любой сборки отсюда предоставляются по запросу (см. раздел о лицензиях выше).
